## ddns-rotation：多机多域名定时轮换解析调度系统

在 `ddnsipv4/` 从零构建，代码已提交 2 个 commit，待推送 GitHub。

**需求边界（用户确认）**
- 服务器开关机由用户在云厂商侧自行设置，本系统**不下发开关机指令**，只做域名轮换解析。
- 机器公网 IP 手动填写（固定 IP）。
- DNS 托管多厂商：Cloudflare / 阿里云 / 腾讯云 DNSPod / name.com 都可能用到。

**技术选型**
- Cloudflare Worker + Hono + D1 + Cron Triggers（每 5 分钟）+ Workers Static Assets 单页后台。
- 表：machines / groups / group_machines / group_domains / credentials / state / logs。
- 排班两模式：`window`（时段命中，支持跨天）、`rotate`（按天轮转，switch_time 前沿用前一天）、`static`。
- 幂等同步：state 表缓存上次解析值，未变化不调厂商 API；自动回填 zone_id/record_id。
